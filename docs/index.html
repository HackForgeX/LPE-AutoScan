About the Project

LPE-AutoScan is a defensive, detection-only Linux security assessment framework written in Python 3.

It automatically enumerates local security configurations, identifies potential privilege-escalation risk factors, correlates findings with security references, and generates structured security reports.

Key Features

  • SUID/SGID binary analysis
  • Sudo configuration analysis
  • File permission analysis
  • Cron job analysis
  • Systemd service analysis
  • Linux capabilities analysis
  • User and group analysis
  • SSH security checks
  • Docker/container detection
  • Kernel/CVE correlation
  • GTFOBins reference mapping
  • Severity and confidence scoring
  • Terminal reports
  • JSON reports
  • HTML reports

Architecture

The toolkit uses a modular scanner architecture. Individual security modules inspect different Linux privilege-escalation attack surfaces and send their findings to the assessment engine.

The project includes documentation covering architecture, methodology, and controlled test-lab procedures.

Safety & Non-Exploitation Policy

LPE-AutoScan is designed as a detection-only security assessment toolkit.

  • No exploit payload execution
  • No shellcode execution
  • No kernel exploit execution
  • No system configuration modification
  • No privilege escalation attempts
  • Read-only security inspection
